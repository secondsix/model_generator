Modbus 点位地址：设备点表文件名含 Modbus（不区分大小写）时启用换算，否则继续处理 OPC 地址。当前支持所提供 WinCC 格式：`3x400525 → HR524`（数字部分减 400001），`0x16 → CO15`（十进制数字减 1，0x 不是十六进制前缀）。其他未支持格式留空并提示。

对文件名含 ZS00990 或 D21 的 Modbus 点表，优先使用内置 D21 东华S09 资料中“功能码”和“地址低位dec”；功能码3输出 HR，功能码1输出 CO。资料来自用户提供的 D21 东华S09 Modbus TCP.xlsx / Sheet1，东华 S09 Modbus TCP 接口20210915.xlsx / Table1 确认4x区和实际射咀温度1007。保压一至四段时间按资料修正为 HR1512/HR1514/HR1516/HR1518，实际射嘴温度修正为 HR1007，修正会显示在处理结果。资料中“实际熔胶时间”有1544和1574两项，留空待核实。运行时不依赖原资料文件路径。数据类型仍取设备点表，采集周期和空配置规则不变；本次不修改缩放、小数位和高低字顺序。

单色第八套备用规则：前七套未匹配时，注射压力一至四段→设定射胶1～4段压力，保压压力/时间一至四段→设定保压1～4段压力/时间，注射速度一至五段（mm/s、%）→设定射胶1～5段速度，冷却时间→实际冷却时间，射嘴温度→实际射嘴温度。第六段速度和其他空白项不新增映射，双色规则不变。

单色第七套备用规则：前六套未匹配时使用指定 ZS451双色_ 注释。一段注射速度的 mm/s 和 % 均对应 ZS451双色_注射速度；一段保压压力、保压时间分别对应 ZS451双色_保压压力、ZS451双色_保压时间；切换保压位置对应 ZS451双色_切换位置。其余按新增表中的非空映射处理，空白项不新增映射，双色规则不变。

单色第六套备用规则：前五套未匹配时，使用用户给定的 ZS474双色_ 注释，射嘴温度使用 ZS474SS_射嘴实际温度。仅一段 mm/s 注射速度新增 ZS474双色_注射速度，百分比及其他段不增加该映射。注释中的“双色”仅为原始文本，此套仍属于单色规则；空白项不新增映射。

单色第五套备用规则：此前规则均未匹配时，按新增 ZS450B_ 注释映射背压、注射时间、螺杆转速、冷却时间、加料时间、切换位置、余料位置和射嘴温度；切换时间→实际值PN切换时间，喷嘴温度→实际值温度喷嘴1。一至六段注射速度（mm/s、%）依次匹配“设定值注入速度”“设定值注入速度1”至“设定值注入速度5”。前缀按原表精确匹配，空白项不新增映射，双色不变。

双色新增备用规则：原有候选未匹配时，尝试 A/B组注射压力1～4、保压压力1～4、注射速度1～6、保压时间1～4、储料位置1～3，以及对应组冷却时间、切保压时间(射胶时间)、切保压位置。特殊映射：A组加料时间→储料时间，B组加料时间→B储料时间；A/B组射出终点位置均可匹配射出终点位置。仅这两类按指定规则使用特殊组别命名，空白项不增加映射，单色规则不变。

单色第四套备用规则：前三套未匹配时再尝试“保压1段压力”至“保压4段压力”、百分比注射速度对应“射出1段速度B”至“射出6段速度B”、切换保压位置→转保压位置、注射终点位置→射出终点。已存在的同名候选保持原优先级；mm/s 不匹配速度B，双色不受影响。

单色第三套备用规则：前两套未匹配时，再匹配一至三段注射速度（mm/s、%）→注射速度1段/2段/3段，切换时间→注射切换时间。冷却时间、余料位置沿用同名匹配。四至六段及本表其他空白项不新增映射；双色规则不变。

单色点位新增备用注释规则：原有候选全部未找到时，尝试“注射压力1”“保压压力1”“注射速度1”“保压时间1”“储料位置1”等对应段号，以及“射出时间”“切保压时间(射胶时间)”“切保压位置”“储料速度1/2/3”“射出终点位置”。原有匹配优先；新表中空白映射不增加候选，仍未匹配时留空。双色规则不变。

文件输入框及选择按钮支持从资源管理器拖入 .xlsx 文件；物模型模式支持一次拖入多个标签库（替换当前选择），其他文件为单选。导出位置支持拖入文件夹。开发环境需安装 `tkinterdnd2`，打包使用项目中的 spec 以包含拖放组件。

点位导入：在下拉框选择“单色注塑机点位导入生成器”，依次选择工艺参数文件、点位导入模板、WinCC 设备点表和输出文件夹。工艺参数文件名包含“单色”或“双色”时自动采用对应规则，读取各文件首个 sheet。每次生成一个“工艺参数文件名_设备点表文件名_点位导入.xlsx”。

工艺参数名称与单位直接写入点位名称、单位。点位标识为名称拼音首字母小写（保留英文字母及数字；首字母冲突时展开中文数字全拼）。按已给出的注释映射提取 OPC 地址首段，例如 `ns=2;i=20250`。WinCC 有符号/无符号整数按位宽转换为 INT/UINT，32/64 位浮点转换为 FLOAT32/FLOAT64，仅输出截图支持的类型。点位标签、协议配置、输出类型、转换配置留空，采集周期固定 1000。

补充明确同义匹配：加料时间→储料时间、周期→循环周期时间、注射/射出终点位置→注射最前位置、料筒/机筒温度各段→对应段温度实际。不将报警、设定温度或相似名称直接当作实际测量点。双色匹配始终保留 A/B 组别。未匹配或同一注释对应多个不同点位时，地址及类型留空；不认识的类型留空。界面列出匹配数量及所有留空原因，源文件不会修改。

标签库生成时，在本次设计表的全部产品间检查名称（先应用单位后缀规则）。仍重复的名称均追加 `_产品名称`，例如“温度_移印”“温度_硬压”；唯一名称保持原样。此规则只修改名称列，标识沿用现有规则。追加后仍重复则在写入前提示。

物模型模式点击“选择文件（多选）”，可按 Ctrl 或 Shift 同时选择多个标签库文件，使用同一模板输出到所选文件夹。每个标签库分别生成对应产品的物模型导入文件，并显示整体进度；输出名称冲突时会在生成前提示。标签库生成器的设计表仍为单选。

物模型导入文件生成器：选择“xxx物模型标签库导入.xlsx”作为源文件，选择物模型导入模板和输出文件夹。读取首个 sheet 的标识、名称、单位及可选说明，分别写入属性标识、属性名称、单位、属性说明。标识不重新生成；来源固定设备、读写类型固定上报、存储方式固定存储。

数据类型规则：有测量单位时默认 double、精度 2；计数单位（次、个、件等）用 int，累计计数用 long。无单位时按名称辅助识别布尔、日期、枚举、文件等，未知用 string。单位列也可明确填写支持的数据类型名称以指定类型（此时输出单位为空）。支持 boolean、date、double、enum、float、int、long、string、geoPoint、file、password。double/float 的配置 scale 与精度一致，数字类型单位原样写入单位列及配置 unit。模板示例中互不一致的单位与精度不会沿用。枚举仅生成类型配置，不虚构枚举选项；实际平台若要求单位编码或枚举选项，需按平台规则补充。

标签库生成器新增单位列，从设计表单位原样读取；旧五列模板会自动补列。先生成标签库，再在物模型模式中选择该文件即可转换。两个模式分别记住源文件、模板和导出路径。

双击 `启动可视化工具.bat` 或打包后的程序，在窗口顶部下拉框切换“物模型导入文件生成器”和“物模型标签库导入生成器”。

标签库模式：选择设计表、标签库导入模板，再点击“选择文件夹”选择保存目录，点击“开始生成”。两个模式分别保留模板与导出路径。

读取设计表第一个 sheet，使用产品名称、物模型类型、物模型名称、单位、备注说明字段。沿用仅处理以“参数”结尾的类型、空白产品名称继承上一产品的规则。标签模式默认保留物模型名称原文，不拆分 A/B 组。

标签模板需包含：标签类型、分类标识、标识、名称、说明。每个产品单独输出一个文件，文件名为“产品名称物模型标签库导入.xlsx”，标签类型固定为 `property`，分类标识默认取产品名称拼音首字母大写；同一设计表中首字母冲突的产品均改用完整拼音大写（移印、硬压同为 YY，因此分别使用 YIYIN、YINGYA；激光打码保持 JGDM），完整标识为 `GY_分类标识_名称拼音首字母大写`，英文及数字保留（英文转大写），说明来自备注说明。示例：`GY_DSZSJ_ZSYLED`。模板示例行会被清除。分类全拼或按下述规则处理后的标签标识仍重复时提示冲突；保存路径不能覆盖源设计表或模板。

标签名称首字母冲突时，同组名称中的中文数字自动改用完整拼音，例如“注射压力三段”生成 `ZSYLSAND`，“注射压力四段”生成 `ZSYLSID`。无冲突的名称仍使用首字母；展开后仍重复的标识继续提示冲突。

同一产品的同名标签均有单位时，导出名称追加单位后缀，再据此生成标识。例如 `打点时间 / μs` → `打点时间微秒`（`DDSJWM`），`打点时间 / ms` → `打点时间毫秒`（`DDSJHM`）；`频率 / Hz` → `频率赫兹`（`PLHZ`），`频率 / KHz` → `频率千赫兹`（`PLQHZ`）。常见时间和频率单位使用中文名，未配置的单位保留原文。无重名的标签保持原名称。缺少单位或加后缀后仍冲突时继续提示，说明保留备注说明。
